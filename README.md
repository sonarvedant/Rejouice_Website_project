# Rejouice — Digital Brand Accelerator UI

A modern, highly animated web experience inspired by the **Rejouice** agency aesthetic. This project features smooth inertia scrolling, synchronized video playback, custom cursor interactions, and responsive editorial typography.
---

## ✦ Features
- **Smooth Inertia Scrolling:** Powered by Locomotive Scroll for seamless, momentum-based viewport navigation.
- **Micro-Interactions & Timelines:** Custom cursor follower, floating glassmorphism elements, animated typography lines, and dynamic video hover reveals via GSAP.
- **Editorial Design System:** Custom typography styling (`Rejouice Headline`), warm editorial palettes, frosted glass aesthetics, and minimalist modern navigation.
- **Brand Hero & Service Showcase:** Split agency model statement sections, layered interactive media cards, and an integrated brand footer.
---

## 🛠️ Built With
- **HTML5** — Semantic, accessible content structure
- **CSS3** — Custom properties, keyframe animations, glassmorphism, and responsive layouts
- **JavaScript** — Interactive logic and animation control
- **[GSAP (GreenSock)](https://greensock.com/)** — Timeline animation sequencing and ScrollTrigger bindings
- **[Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll)** — Inertia-driven smooth scrolling framework
